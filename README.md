# 📌 About The Project

**STRIST** is a modern Front-End website created with a focus on
professional design, responsive layouts and a smooth browsing experience.

The project was developed as part of my Front-End development journey
to practice creating real-world websites with modern UI/UX principles.

- 🚀 Modern and professional UI
- 🎨 Clean visual design
- 📱 Fully responsive layout
- 💻 Desktop & laptop support

- ⚡ Interactive elements
- 🖼️ Attractive visual sections
